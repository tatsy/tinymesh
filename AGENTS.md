# tinymesh agent guide

When a repository's documentation and its existing code disagree, follow the
conventions used in the existing code, and in your final reply point out each
inconsistency you found between the documentation and the code.

## Project Overview

- This project offers a set of geometry processing algorithms for 3D triangular meshes with a half-edge data structure.
- Supported algorithms are listed in `README.md`

## Guidelines

- Do NOT add/edit/delete files without an explicit permission.
- Write code comments in English such that the repository can be published online.
- Provide detailed code-level explanations and line numbers when you provide the required updates.
- Keep `README.md` simple. Avoid any redundant comments and explanations.
